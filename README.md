# corentinrenard.com

[![Deploy](https://github.com/Aqu1tain/corentinrenard.com/actions/workflows/deploy.yml/badge.svg)](https://github.com/Aqu1tain/corentinrenard.com/actions/workflows/deploy.yml)

My portfolio. Built with Nuxt. Yes, the capybara is intentional.

## Run it locally

Pull the image:

```bash
docker pull ghcr.io/aqu1tain/corentinrenard.com:latest
```

Run it:

```bash
docker run -p 3000:3000 ghcr.io/aqu1tain/corentinrenard.com:latest
```

Open [localhost:3000](http://localhost:3000). That's it.

## Development

```bash
pnpm install
pnpm dev
```
